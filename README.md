# Pallav Kafle — Portfolio

A high-performance, fully accessible personal portfolio built with Next.js 15, React 19, and Tailwind CSS. 

🔗 **Live Site:** [pallavkafle.com.np](https://pallavkafle.com.np)

## ✨ Features
- **Editorial Design:** Custom typography (Instrument Serif, Inter, JetBrains Mono) with a dark OLED aesthetic.
- **Framer Motion Animations:** Scroll-linked reveals, reduced-motion support, and smooth layout transitions.
- **Server Components:** GitHub API fetching is cached and rendered server-side to avoid rate limits.
- **Working Contact Form:** Validated with Zod, protected by a honeypot, and delivers emails via Nodemailer.
- **SEO Optimized:** Dynamic `sitemap.xml`, `robots.txt`, JSON-LD schema, and Open Graph images.

## 🛠️ Tech Stack
- **Framework:** Next.js 15 (App Router)
- **UI & Styling:** React 19, Tailwind CSS, Framer Motion
- **Icons:** Lucide React, React Icons
- **Validation & Email:** Zod, Nodemailer
- **Deployment:** Vercel
